# Segurança

## Versões

O projeto está em desenvolvimento alpha, sem linha estável ou prazo garantido de suporte. Correções serão direcionadas à versão em desenvolvimento.

## Relatar uma vulnerabilidade

Não publique detalhes exploráveis, documentos pessoais ou credenciais em uma issue pública. Se a aba Security disponibilizar relato privado, use esse canal. Caso não esteja disponível, abra uma issue apenas solicitando um canal privado, sem incluir a vulnerabilidade.

Informe versão/commit, ambiente, impacto e reprodução mínima com dados sintéticos.

## Limites atuais

A demo abre documentos JSON e usa um componente nativo instalado no Windows. Não trate o formato como adequado a arquivos hostis sem revisão adicional. O reconhecimento atual é local; a demo grava recuperação automática em `local/`. Revise esses dados antes de compartilhar qualquer pasta.
